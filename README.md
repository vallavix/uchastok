# Участок

Рабочее место начальника участка по электромонтажу: план по проекту, стадии
готовности квартир, ведомость материалов и объёмы по бригадам.

**Открыть: https://vallavix.github.io/uchastok/**

Работает в браузере, ничего не устанавливается и никуда не отправляется —
все отметки лежат в памяти самого браузера на компьютере. После первого
открытия работает и без интернета.

---

## Как начать

Приложение пустое: объект в него загружается файлом.

1. Открыть ссылку.
2. Нажать **«Выбрать файл объекта»** и указать файл вида `..._объект.json`.
3. Всё подставится: корпуса, этажность, номера квартир, типы, спецификации,
   а если в файл вложены данные обхода — то и они.

Файл объекта готовит тот, кто вёл проект (см. «Как собрать файл объекта»).

## Что внутри

**Сводка** — сколько сдано, установлено и проверено; таблица оборудования
по проекту против факта.

**Квартиры** — сетка всех квартир с типом, местом на этаже и тремя стадиями.
Фильтры: не сдано, сдано, с замечаниями, без типа.

**Карточка квартиры** — стадии, факт против проекта с ручной правкой количеств,
замечания из обхода и полная спецификация по типу квартиры.

**Материалы** — ведомость по корпусу: нужно / смонтировано / осталось,
с поиском и выгрузкой в CSV.

**Бригады** — кто сколько сделал, по корпусу или по всему объекту, с выгрузкой в CSV.

**Раскладка** — этажность, количество квартир на этаже и кто на каком месте
по стояку. Этажи с другим количеством квартир описываются отдельно.

**Данные обхода** — загрузка выгрузки из приложения
[«Электро-приёмка»](https://vallavix.github.io/elektro-priemka/).

## Три стадии по каждой квартире

| Стадия | Кто ставит |
|---|---|
| Установлено (чистовая) | начальник участка |
| Проверено обходом | приходит из выгрузки обхода, вручную не переключается |
| Сдано заказчику | начальник участка |

«Проверено» намеренно нельзя поставить руками: иначе картина начальника
и картина монтажников разъедутся, и связка потеряет смысл.

## Связка с обходом

В «Электро-приёмке»: **Выгрузка → Выгрузка для начальника**. Получается
небольшой файл без фотографий — уходит в мессенджер мгновенно. Здесь он
открывается в разделе «Данные обхода».

Подтягиваются: что принято по каждой квартире, замечания, количества и
разбивка по бригадам. Отметки «Установлено» и «Сдано» и ручные количества
начальника импорт не трогает.

Полная резервная копия обхода тоже подойдёт, но она тяжёлая из-за фотографий.

## Как собрать файл объекта

Скриптом `build-object.py` — он читает рабочие `.xlsx` со спецификациями ЭОМ
и, если указать, резервную копию обхода:

```
pip3 install openpyxl
python3 build-object.py
```

Пути и раскладку по стоякам правишь в блоке `НАСТРОЙКИ` в начале скрипта.
Раскладка — это «кто стоит на месте №1, №2 и так далее»; берётся с плана этажа.

Проверить раскладку можно по самому проекту: в шапках ЭОМ перечислены номера
квартир каждого типа, и у верной раскладки все номера одного типа дают одно
и то же место на этаже.

## Обновление

При правке файлов поднимай версию кэша `V` в `sw.js` — иначе браузер отдаст
старую версию из памяти.
